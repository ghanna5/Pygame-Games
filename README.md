# Pygame-Games

Games built with Python and Pygame for CPSC 386 (Introduction to Game Design and Production) at Cal State Fullerton.

| Folder | Game |
| --- | --- |
| `blackjack` | Text based Blackjack with saved player balances |
| `slide-puzzle` | Sliding tile puzzle |
| `tictactoe` | Tic Tac Toe with a computer opponent |
| `pong` | Two player Pong |
| `galaga` | Galaga style space shooter with a leaderboard |

## Run
```
cd galaga
pip install -r requirements.txt
python galaga.py
```
